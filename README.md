# Eat Amor — Sistema de Control de Inventarios

Sistema web para controlar el inventario de una crepería con varias sucursales.
Proyecto de titulación de Ingeniería en Sistemas Computacionales.

> Los datos incluidos son de ejemplo. No contienen información real del negocio.

## Qué hace
- Registra entradas y salidas de producto por sucursal.
- Tiene inicio de sesión con roles: administrador y empleado.
- Incluye un punto de venta para registrar ventas.
- Cada rol tiene su propio panel de control.

## Tecnologías
PHP (PDO) · MySQL / MariaDB · JavaScript · HTML5 · CSS3 · XAMPP

## Cómo ejecutarlo en local
1. Instala XAMPP e inicia Apache y MySQL.
2. Copia la carpeta del proyecto en `htdocs`.
3. Crea una base de datos llamada `eat_amor` en phpMyAdmin e importa el archivo .sql.
4. Abre `http://localhost/eat_amor` en tu navegador.
